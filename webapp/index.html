Audition
C3

Computer keys: Z–M and Q–U play two octaves. MIDI input plays too.

    Loaded files

    Drop .syx files here, or press Load .syx files. TQ5, TX81Z, DX11, DX21, DX27 and DX100 banks and single voices are read.

    User bank (100 voices)

    Drag voices onto slots, or select a voice and press Enter on a slot. Alt+arrow keys move the selected slot.

      Before you start
      • Use desktop Chrome or Edge.
      • Use a USB data cable straight into the computer, with no hub.
      • Close other MIDI apps, DAWs and editor tabs. This page also releases its own editor ports while writing.
      • Make sure the FM-1 is charged or powered.
      • Keep the official V15 recovery path in mind: resume in this page, then the Unbricker, then the Transporter dongle.
      Firmware

      Checking the firmware package…

      1. Connect

      Not connected

      2. Back up

      Recommended before your first custom install: switch the FM-1 to UBOOT and make a full-flash dump with MvaveFM1Unbricker (softkey, then backup; Windows or Linux).

      3. Install

      While writing: do not unplug, do not close this page, do not let the FM-1 power off. It restarts twice.
